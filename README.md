# Mic-Effect-Tester

## Overview  

This tool is designed to verify the effectiveness of various microphone effects by simultaneously playing and recording audio through user-defined input and output endpoints. By providing a visualized waveform comparison, users can easily analyze whether specific audio processing effects are active and functioning as expected.

  
  
## Features  

Currently, the software supports testing for the following effects:

-AINR (AI Noise Reduction)

-Compressor

-Limiter  


    
## Installation

1.Navigate to the Releases page.  

2.Download the latest Mic.Effect.Tester.exe.  

3.Run the application (no installation required).
