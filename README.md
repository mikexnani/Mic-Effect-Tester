# Mic-Effect-Tester

## Overview  

This tool is designed to verify the effectiveness of various microphone effects by simultaneously playing and recording audio through user-defined input and output endpoints.   
By providing a visualized waveform comparison, users can easily analyze whether specific audio processing effects are active and functioning as expected.

  <br>
  <br>
  
## Features  

Currently, the software supports testing for the following effects:

-AINR (AI Noise Reduction)
-Compressor
-Limiter  

<br>
<br>
    
## How to use

**1. Launch the Application**<br>
Double-click Mic_Effect_Tester.exe to start the program.

**2. Select Input Device**<br>
Click "Select Input Endpoint" and double-click the microphone device you wish to test from the drop-down menu.

**3. Select Output Device**<br>
Click "Select Output Endpoint" and double-click the device you want to use for audio playback from the drop-down menu.

**4. Choose Effect Function**<br>
Click the button for the specific function you want to test (AINR, Limiter, or Compressor) to open its settings window.

**5. Record First Segment**<br>
Click "Start" to begin recording the first audio segment. A prompt window will appear once playback is finished.

**6. Toggle Effect and Record Second Segment**<br>
Switch the effect setting on  software toggle, then click "OK" in the prompt window to proceed with the second recording.

**7. Compare Results**<br>
Analyze the visual waveforms of the recorded tracks to verify whether the effect has been successfully applied.
